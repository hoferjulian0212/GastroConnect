1. CORE CONCEPT (VERY IMPORTANT)
--------------------------------------------------

The indicator is NOT a fixed pill.

It must behave like a LIQUID DROPLET:
- It stretches toward the next item while dragging
- It keeps a connection to the previous position
- It forms a "teardrop / blob" shape between two points

This is called a "metaball / liquid interpolation effect"

--------------------------------------------------

Instead of ONE bubble, create TWO:

A) Base bubble (current position)
B) Target bubble (next item)

--------------------------------------------------

Use ONE of the following approaches:

4. SVG METABALL IMPLEMENTATION (EXACT)
--------------------------------------------------

Render:

<svg class="liquid-svg">
  <path d={dynamicPath} />
</svg>

You must:

- Calculate positions of:
  circle A (current item)
  circle B (next item based on drag)

- Compute a connecting path between them
  (Bezier curves)

Path must update on EVERY drag frame.

--------------------------------------------------
5. DRAG-BASED MORPHING (CRITICAL)
--------------------------------------------------

While dragging:

- Distance between A and B increases
→ connection stretches

- When close:
→ shape becomes round

- When far:
→ shape becomes long "droplet"

Use:

distance = abs(positionA - positionB)

Then:

- Increase horizontal stretch
- Reduce vertical radius slightly
- Add curvature to path

--------------------------------------------------
6. REAL-TIME INTERPOLATION (MISSING BEFORE)
--------------------------------------------------

DO NOT snap between items.

Instead:

- Always calculate:
  currentIndex (floor)
  nextIndex (ceil)

- progress = decimal between them (0 → 1)

Then:

centerX = lerp(A.center, B.center, progress)

BUT ALSO:
- Keep BOTH circles alive
- Not just one interpolated position

This is what creates the liquid connection.
