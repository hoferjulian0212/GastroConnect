--------------------------------------------------

Use Framer Motion drag.

<motion.div

4. LIQUID INDICATOR (REAL IMPLEMENTATION)
--------------------------------------------------

Add:

Animate like this:

animate={{
  x: interpolatedX,
  width: interpolatedWidth,
  scaleX: velocity > 0 ? 1.15 : 0.95,
  scaleY: velocity > 0 ? 0.85 : 1.05
}}

--------------------------------------------------
5. INTERPOLATION (THIS CREATES "LIQUID")
--------------------------------------------------

DO NOT snap directly to items.

Instead:

- Calculate nearest TWO items based on drag position
- Interpolate between them:

progress = how far between item A and B

x = lerp(A.offsetLeft, B.offsetLeft, progress)
width = lerp(A.width, B.width, progress)

This creates the "melting / morphing" effect.

--------------------------------------------------
6. VELOCITY-BASED DEFORMATION (TINDER FEEL)
--------------------------------------------------

Track velocity:

const velocity = useVelocity(dragX)

Use it to deform bubble:

- Fast swipe → stretched horizontally
- Slow movement → round shape

Example:
scaleX = 1 + Math.min(Math.abs(velocity) / 1000, 0.2)
scaleY = 1 - Math.min(Math.abs(velocity) / 1200, 0.15)
